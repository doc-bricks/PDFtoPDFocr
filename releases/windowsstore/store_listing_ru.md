Краткое описание:
Преобразование сканированных PDF и изображений в доступный для поиска текст с OCR.

Описание:
PDFtoPDFocr — это надежное локальное приложение для преобразования сканированных документов PDF и изображений в файлы с возможностью полнотекстового поиска. Приложение использует движок Tesseract OCR и выполняет всю обработку строго локально на вашем компьютере.

- Пакетное добавление нескольких PDF-файлов через диалог выбора или перетаскивание (Drag-and-Drop)
- Быстрый выбор языка распознавания OCR
- Наглядное отображение прогресса и статуса обработки каждого документа
- Сохранение обработанных файлов с суффиксом _ocred.pdf по умолчанию
- Настройка папки экспорта и языка пользовательского интерфейса
- 100% локальная обработка без передачи данных во внешние облачные сервисы

Целевая аудитория:
Идеально подходит для оцифровки сканированных документов, писем, счетов, квитанций, договоров и архивных материалов. Проект распространяется по лицензии MIT; подробнее в файле LICENSE.
