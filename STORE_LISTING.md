## English

### Short Description (max 100 chars)
Make scanned PDFs searchable - local OCR processing

### Description (max 10,000 chars)
PDF OCR Converter turns scanned PDF files into searchable PDFs using text recognition (OCR) powered by Tesseract.

FEATURES:
- Batch Processing: Convert multiple PDFs at once - via file picker or drag & drop
- Selectable OCR Language: Quick selection for German, English, French, and Spanish
- Multi-Language: Support for dozens of languages (German, English, French, Spanish and many more)
- Auto-Download: Missing language packs are downloaded automatically from GitHub
- Portable Tesseract: No separate Tesseract OCR installation needed - everything is built in
- Easy to Use: Select files, choose language, click start - done
- Original File Preserved: Result is saved as a new file with "_ocred.pdf" suffix
- Progress Indication: Status of each file shown with color coding (green = done, orange = error)
- Works Offline: After the first language pack download, OCR processing works without internet

FOR WHOM:
- Anyone who wants to make scanned documents (contracts, invoices, letters, forms) searchable
- Offices and archivists who need to process large quantities of scanned PDFs
- Users looking for a free alternative to expensive OCR software like ABBYY or Nuance

BENEFITS:
- Completely free - no hidden costs, no ads
- No third-party software installation required
- Privacy-friendly: All data stays locally on your computer
- Simple drag & drop interface
- Batch processing saves time with many documents
