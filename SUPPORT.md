## Frequently Asked Questions (FAQ)

### 1. Where are the converted files saved?
By default, converted PDFs are saved in the same directory as the source file with `_ocred.pdf` appended to the filename. You can also configure a custom export directory in the application settings.

### 2. Are my PDF documents uploaded to the cloud?
No. All OCR conversions and file handling take place 100% locally on your computer.

### 3. Which languages are supported for OCR?
PDFtoPDFocr includes standard support for German, English, French, and Spanish, and can automatically download additional Tesseract language packages from GitHub if needed.
